# slipway-demo (project id `adlc-demo`)

Demo monorepo delivered end to end by the [slipway](https://github.com/integranz/slipway) Claude Code plugin, which implements the Agentic Delivery Lifecycle (ADLC). The project id `adlc-demo` names the Azure resources and image repositories and is intentionally unchanged.

| App | Path | Stack | Port | Health |
|---|---|---|---|---|
| api | `apps/api` | .NET 8 minimal API (`Api.sln`: `src/Api`, `tests/Api.Tests`) | 8080 | `/health` returns `{status, version, startedAt}` |
| web | `apps/web` | React 19 + Vite 8; served by nginx in the container once dockerized (dev server: 5173) | 8080 | `/` |

Versioning: [Nerdbank.GitVersioning](https://github.com/dotnet/Nerdbank.GitVersioning) (`version.json`). CI stamps the version into both images (`-p:InformationalVersion` for the API, `VITE_APP_VERSION` for the web) so a deployment can be verified against its tag.

Local run:
```
ASPNETCORE_HTTP_PORTS=8080 dotnet run --project apps/api/src/Api   # http://localhost:8080/health (containers set this variable)
npm --prefix apps/web install && npm --prefix apps/web run dev   # http://localhost:5173 (proxies /api to :8080)
```
Tests: `dotnet test apps/api` and `npm --prefix apps/web test`.

Containers: `/slipway:dockerize <app>` builds one image; `VERSION=$(nbgv get-version -v SemVer2) docker compose up --build` runs both (api on :8080, web on :8081 proxying `/api/` to the api).

Delivery configuration, rules and workflows are generated by `/slipway:bootstrap`; `AGENTS.md` is the routing page for humans and agents.

Verified deployments: every `/slipway:verify <env> <tag>` run leaves its claim table in `.slipway/evidence/<tag>.md` (latest: [0.1.24](.slipway/evidence/0.1.24.md), 19/19 confirmed). Deployments themselves are applied only after a human approves the `dev` environment in GitHub Actions.
