# Delivery setup checklist — adlc-demo

Generated by `/slipway:bootstrap` from `.slipway/config.yaml`. These are the one-time, human-only prerequisites; nothing here is created by an agent. Re-run the scaffold after changing options to refresh this file.

## 1. GitHub → `integranz/slipway-demo` → Settings → Secrets and variables → Actions
| Name | Kind | Value |
|---|---|---|
| `AZURE_CLIENT_ID` | secret | Application (client) ID of the app registration below |
| `AZURE_TENANT_ID` | secret | Directory (tenant) ID |
| `AZURE_SUBSCRIPTION_ID` | secret | Subscription ID |
| `DOCKERHUB_TOKEN` | secret | Docker Hub personal access token, or an organization access token (recommended for CI); needed because `dhi.io` requires a login |
| `DOCKERHUB_USERNAME` | variable | Docker Hub username (organization name if using an organization token) |

```
gh secret set AZURE_CLIENT_ID -R integranz/slipway-demo
gh secret set AZURE_TENANT_ID -R integranz/slipway-demo
gh secret set AZURE_SUBSCRIPTION_ID -R integranz/slipway-demo
gh secret set DOCKERHUB_TOKEN -R integranz/slipway-demo
gh variable set DOCKERHUB_USERNAME -R integranz/slipway-demo --body "<docker hub username>"
```

## 2. GitHub → Settings → Environments
Create `dev` with **Required reviewers** (yourself at least). The CD job runs with `environment: dev`; approval happens before `terraform apply` of `infra/app`.
```
gh api -X PUT repos/integranz/slipway-demo/environments/dev --input - <<JSON
{ "reviewers": [ { "type": "User", "id": $(gh api user --jq .id) } ],
  "deployment_branch_policy": { "protected_branches": false, "custom_branch_policies": true } }
JSON
gh api -X POST repos/integranz/slipway-demo/environments/dev/deployment-branch-policies -f name=main -f type=branch
```
The branch policy limits deployments to `main`; CD is dispatched on that branch with an immutable tag input.

> Steps 3–5 are automated by `bash .slipway/setup-azure.sh` (dry run) / `--apply` (idempotent, human-only). The commands below are what it runs.

## 3. Entra ID app registration for CI/CD (OIDC, no client secret)
```
az account set --subscription <subscription id>
APP_ID=$(az ad app create --display-name sp-adlc-demo-github --query appId -o tsv)
az ad sp create --id "$APP_ID" >/dev/null
APP_OBJ=$(az ad app show --id "$APP_ID" --query id -o tsv)
az ad app federated-credential create --id "$APP_OBJ" --parameters '{
  "name": "github-main", "issuer": "https://token.actions.githubusercontent.com",
  "subject": "repo:integranz/slipway-demo:ref:refs/heads/main",
  "audiences": ["api://AzureADTokenExchange"] }'
az ad app federated-credential create --id "$APP_OBJ" --parameters '{
  "name": "github-env-dev", "issuer": "https://token.actions.githubusercontent.com",
  "subject": "repo:integranz/slipway-demo:environment:dev",
  "audiences": ["api://AzureADTokenExchange"] }'
echo "AZURE_CLIENT_ID=$APP_ID  AZURE_TENANT_ID=$(az account show --query tenantId -o tsv)  AZURE_SUBSCRIPTION_ID=$(az account show --query id -o tsv)"
```

## 4. Terraform state storage (once; Entra ID auth only, no storage keys)
```
az group create -n rg-adlc-tfstate -l westeurope
az storage account create -n stadlctfstate -g rg-adlc-tfstate -l westeurope \
  --sku Standard_LRS --kind StorageV2 --min-tls-version TLS1_2 --allow-blob-public-access false --allow-shared-key-access false
az storage container create -n tfstate --account-name stadlctfstate --auth-mode login
```

## 5. Resource group and RBAC
```
az group create -n rg-adlc-demo-dev -l westeurope
SUB=$(az account show --query id -o tsv); SP=$(az ad sp show --id "$APP_ID" --query id -o tsv)
# CI/CD service principal: apply infra/app, push images, read/write app-layer state
az role assignment create --assignee-object-id "$SP" --assignee-principal-type ServicePrincipal --role Contributor \
  --scope /subscriptions/$SUB/resourceGroups/rg-adlc-demo-dev
az role assignment create --assignee-object-id "$SP" --assignee-principal-type ServicePrincipal --role "Storage Blob Data Contributor" \
  --scope /subscriptions/$SUB/resourceGroups/rg-adlc-tfstate/providers/Microsoft.Storage/storageAccounts/stadlctfstate/blobServices/default/containers/tfstate
# AcrPush on acradlcdemo is assigned by infra/foundation once the registry exists (output: acr_id).
# You (human): apply infra/foundation, set Key Vault secret values
ME=$(az ad signed-in-user show --query id -o tsv)
az role assignment create --assignee-object-id "$ME" --assignee-principal-type User --role "User Access Administrator" --scope /subscriptions/$SUB/resourceGroups/rg-adlc-demo-dev
az role assignment create --assignee-object-id "$ME" --assignee-principal-type User --role "Storage Blob Data Contributor" \
  --scope /subscriptions/$SUB/resourceGroups/rg-adlc-tfstate/providers/Microsoft.Storage/storageAccounts/stadlctfstate
```
