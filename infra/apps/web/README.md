# infra/apps/web — adlc-demo (dev, compute: Azure Container Apps)

Generated by slipway from `templates/compute/aca/per-app/infra/apps`. Owns exactly one container app, `web`, in the shared
environment `cae-adlc-demo-dev` (created by `infra/foundation`), pulling `acradlcdemo.azurecr.io/adlc-demo/web:<image_tag>` with the identity `id-adlc-demo-dev`.
Other apps have their own root module and state, so deploying `web` never plans another app's image.

| Command | Who |
|---|---|
| `/slipway:plan dev --layer apps/web --image-tag <tag>` | anyone; read-only |
| `/slipway:deploy web <tag> dev` | triggers `slipway-demo-web-cd`: plan job, then apply behind the `dev` environment approval |

Never apply this layer from a laptop: the guard hook blocks it and the state key (`adlc-demo/apps/web/dev.tfstate`) is written by the CD identity.
