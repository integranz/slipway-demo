# infra/apps/api — adlc-demo (dev, compute: Azure Container Apps)

Generated by slipway from `templates/compute/aca/per-app/infra/apps`. Owns exactly one container app, `api`, in the shared
environment `cae-adlc-demo-dev` (created by `infra/foundation`), pulling `acradlcdemo.azurecr.io/adlc-demo/api:<image_tag>` with the identity `id-adlc-demo-dev`.
Other apps have their own root module and state, so deploying `api` never plans another app's image.

| Command | Who |
|---|---|
| `/slipway:plan dev --layer apps/api --image-tag <tag>` | anyone; read-only |
| `/slipway:deploy api <tag> dev` | triggers `slipway-demo-api-cd`: plan job, then apply behind the `dev` environment approval |

Never apply this layer from a laptop: the guard hook blocks it and the state key (`adlc-demo/apps/api/dev.tfstate`) is written by the CD identity.
