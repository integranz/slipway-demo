# infra/app — adlc-demo (dev, compute: Azure Container Apps)

Generated by slipway from `templates/compute/aca/files/infra/app`. Owns the Container Apps environment `cae-adlc-demo-dev` and one container app per app (`api`, `web`), pulling `acradlcdemo.azurecr.io/<repo>:<image_tag>` with the identity `id-adlc-demo-dev`.

| Command | Who |
|---|---|
| `/slipway:plan dev --layer app --image-tag <tag>` | anyone; read-only |
| `/slipway:deploy <tag> dev` | triggers `cd.yml`: plan job, then apply behind the `dev` environment approval |

Never apply this layer from a laptop: the guard hook blocks it and the state key (`adlc-demo/app/dev.tfstate`) is written by the CD identity.
